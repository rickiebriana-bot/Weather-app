Instrument · Apparent Temperature

What it actually feels like outside.

A blend of NOAA's heat index and wind chill models, tuned across the transition zone and adjusted for cloud cover, using live data from Open‑Meteo.

Data: Open‑Meteo (open-meteo.com), no API key required. "Now" uses live current conditions; the 9 days after that use daily aggregated highs/lows, mean humidity, max wind, and mean cloud cover, so they're a coarser estimate than the live reading. Formula: NOAA Rothfusz heat index regression for T ≥ 80°F, NWS wind chill for T ≤ 50°F with wind > 3 mph, linear blend between, with a cloud‑cover based solar adjustment layered on top. The Outdoor Score blends temperature comfort, wind, sun/cloud, and humidity into a base score, then applies a rain multiplier built from hourly data — so brief showers, all-day rain, and overnight-only rain are scored differently. This is an independent implementation and is not affiliated with AccuWeather's RealFeel®.
